布洛酸鹼理論 (二)

兩性物質 · 質子轉移相對性 · 平衡方向判定
一、布洛酸鹼與兩性物質 核心定義
1. 布洛酸 (Acid)

含有 可解離出 H⁺ (質子) 的人。

例：NH₃(aq) → NH₂⁻ + H⁺
因此 NH₃ 是一種布洛酸
2. 布洛鹼 (Base)

可與 H⁺ (質子) 結合 的人。

例：NH₃ + H⁺ → NH₄⁺
因此 NH₃ 也是一種布洛鹼
★ 兩性物質 (Amphiprotic)：
可解離出 H⁺，也可與 H⁺ 結合。
👉 NH₃ 為兩性物質！
此外，常考經典兩性物質：
• H₂O (可變 OH⁻ 或 H₃O⁺)
• HCO₃⁻ (可變 CO₃²⁻ 或 H₂CO₃)
二、質子轉移判斷 水的兩性
反應 ①：HCO₃⁻ + H₂O ⇌ OH⁻ + H₂CO₃
• H₂O 釋出 H⁺ 變 OH⁻ 👉 布洛酸
• HCO₃⁻ 接 H⁺ 變 H₂CO₃ 👉 布洛鹼
質子轉移：H₂O 轉移 H⁺ 給 HCO₃⁻
反應 ②：HCl + H₂O → H₃O⁺ + Cl⁻
• HCl 提供 H⁺ 👉 布洛酸
• H₂O 接受 H⁺ 👉 布洛鹼
質子轉移：HCl 轉移 H⁺ 給 H₂O
★ 板書重要結論：
在單一反應方程式中，物質只能常態表現為 酸 或 鹼 其中一種角色！
三、酸鹼的相對性剖析 核心深度
疑問：為什麼 HCO₃⁻ 在水中不能當布洛酸？

HCO₃⁻ 結構明明有 H，為什麼溶於水中時，卻是表現出鹼性，而非釋出質子當酸？

原因：兩者酸性強弱不同！
• H₂O ⇌ H⁺ + OH⁻ （解離平衡常數K）
• HCO₃⁻ ⇌ H⁺ + CO₃²⁻ （解離平衡常數K）
👉 酸性：H₂O > HCO₃⁻（解離優先權）

H₂O 比 HCO₃⁻ 更容易解離，因此水有產生 H⁺ 的優先權！

而 HCO₃⁻ 在 H₂O 存在時只能屈居小弟，無法產生 H⁺，只能被動接受 H⁺。

★ 展氏金句口訣：
故布洛酸及布洛鹼 不是絕對，
而是 相對 的！
四、平衡方向判定 考題實戰
題型 1：NH₄⁺ + OH⁻ ⇌ H₂O + NH₃
① 平衡方向：向 右
理由：強酸 + 強鹼 → 弱酸 + 弱鹼
• 酸性：NH₄⁺ > H₂O
• 鹼性：OH⁻ > NH₃
② 角色判定：
• 布洛酸：NH₄⁺
• 布洛鹼：OH⁻
題型 2：HCO₃⁻ + NH₃ ⇌ NH₄⁺ + CO₃²⁻
① 平衡方向：向 左
理由：鹼性：NH₃ < CO₃²⁻（或酸性 NH₄⁺ > HCO₃⁻）
② 正反應角色判定：
• 布洛酸：HCO₃⁻
• 布洛鹼：NH₃
③ 共軛酸鹼對 (Conjugate Pair)：
👉 HCO₃⁻ / CO₃²⁻ 及 NH₄⁺ / NH₃
💡 化學平衡大原則：反應永遠自發趨向生成更弱的酸與更弱的鹼！
🧠 【展氏新解】延伸思維：酸鹼強弱決定化學命運
競爭平衡 · 深入推導
📌 A. 為什麼 HCO₃⁻ 在水中表現為水解（產生OH⁻）而非酸解離？

兩性酸式鹽陰離子（如 HCO₃⁻、HS⁻、HPO₄²⁻）在水中同時存在兩種競爭反應：

  • 解離（當酸）：HCO₃⁻ ⇌ H⁺ + CO₃²⁻，Ka2 ≈ 4.7 × 10-11
  • 水解（當鹼）：HCO₃⁻ + H₂O ⇌ H₂CO₃ + OH⁻，Kb = Kw / Ka1 = 10-14 / (4.4 × 10-7) ≈ 2.3 × 10-8
數值比較：Kb (2.3 × 10⁻⁸) > Ka2 (4.7 × 10⁻¹¹)，故水溶液呈弱鹼性！
📌 B. 共軛酸鹼對的「反比定律」與平衡移動推力

在水溶液共軛體系中，酸的強度與其共軛鹼的強度呈完全反比關係（Ka · Kb = Kw）：

  • 酸越強，其共軛鹼結合質子的能力越弱（例如 HCl 強酸，Cl⁻ 幾乎無結合質子能力）。
  • 平衡推動力：化學平衡永遠由「推質子能力強的酸」推向「保留質子能力強的弱酸」。
  • 在反應 HCO₃⁻ + NH₃ ⇌ NH₄⁺ + CO₃²⁻ 中，因 NH₄⁺ 之酸性強於 HCO₃⁻，逆反應強烈推向左邊！
